Sensors & Smart Lighting Architecture

Pragmatic, low-power sensor layout and decoupled smart lighting routines by zone

🛋️ 1 mmWave (Living + Dining Coverage)
mmWave presence is mounted high at the curtain pelmet pointing lengthwise South through both Living Room and Dining Room. Covers both lounge and dining table without false triggers through bedroom walls.
🚿 "Wasp in a Box" (Bathrooms)
Uses battery Door Contact + PIR Motion. When motion is detected and the door closes, occupancy locks ON indefinitely. Lights NEVER shut off while showering or on the toilet!
⚡ Smart Switches (Relay Mode)
Most rooms use neutral-powered smart relays for standard downlights. Dining is the exception: its H1 press controls always-powered T2 smart bulbs wirelessly. Physical relay operation remains available when automation is offline.
🔒 100% Local-First Control
All sensors, relays, and automations run 100% locally on Home Assistant Green + Zigbee 3.0. Zero cloud lag, zero subscriptions, and fully operational even during internet outages.
✋ Wall-switch manual bypass
Press ON: keep that lighting circuit on for 2 hours, ignoring its normal vacancy-off timer. If a sensor already turned a relay light on, press OFF then ON to request the hold; do not assume double-press support. If the room is still occupied when the hold expires, leave the light on; otherwise start the normal vacancy delay then.
Press OFF: turn it off immediately and block sensor auto-on until the zone clears and a new arrival occurs, or until another ON press.
Scope: sensor-controlled lights only. Closed-door bathroom occupancy still prevents automatic shutoff during a shower; the heater's separate 20-minute auto-off is never bypassed. AC, fans, curtains, and manual-first bedrooms keep their own controls.
Implementation: trigger the hold from a physical H1/Z1 switch action, not from a light state change caused by automation. Confirm action-event support for the chosen integration; use a per-circuit toggle and timer in Home Assistant.

# Home Assistant Template Binary Sensor: Bathroom Occupancy (Wasp in a Box)
# Combines Door Contact Sensor + PIR Motion Sensor
# Illustrative occupancy input only: add the manual-hold condition to any
# light-off automation; never apply the lighting hold to the heater timer.
template:
  - binary_sensor:
      - name: "Master Bath Occupied"
        device_class: occupancy
        state: >
          {{ is_state('binary_sensor.master_bath_door', 'off') or is_state('binary_sensor.master_bath_motion', 'on') }}
        auto_off:
          seconds: 90

# Automation: Turn ON lights with Time-Conditioned Nightlight
automation:
  - alias: "Master Bath: Light Occupancy Trigger"
    trigger:
      - platform: state
        entity_id: binary_sensor.master_bath_motion
        to: "on"
    action:
      - choose:
          # Late-Night Piddle Mode (11PM - 6:30AM) -> Dim mirror light only
          - conditions:
              - condition: time
                after: "23:00:00"
                before: "06:30:00"
            sequence:
              - service: light.turn_on
                target:
                  entity_id: light.master_bath_mirror
                data:
                  brightness_pct: 15
                  color_temp_kelvin: 2200
        # Daytime / Normal -> Full Downlights
        default:
          - service: light.turn_on
            target:
              entity_id: light.master_bath_downlights
            data:
              brightness_pct: 100
              color_temp_kelvin: 4000

# Proposed logic outline — adapt to actual H1/Z1 events during commissioning
# Apply to each sensor-controlled LIGHTING circuit, including dining's T2 bulbs.
Physical wall ON action:
  turn the circuit on; clear manual-OFF latch
  start/restart its 2-hour manual-hold timer
  if a sensor already lit a relay circuit, OFF then ON requests the hold
Physical wall OFF action:
  turn the circuit off immediately; cancel the hold
  suppress sensor auto-ON until the zone clears and a new arrival occurs
Vacancy auto-OFF:
  run only when manual hold is inactive and the zone has been vacant
  for its usual room-specific delay
When hold expires:
  if occupied, keep lights on; if vacant, start the normal vacancy delay
Bathroom exception:
  door closed + established occupancy blocks auto-OFF even after hold expiry
Keep water-heater 20-minute auto-OFF independent of this lighting logic.
Do not infer a physical press from a relay/light state change: verify the
wall-switch action event exposed by the selected Home Assistant integration.
